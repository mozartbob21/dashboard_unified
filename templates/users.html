Как считаются показатели

Новое посещение начинается после 30 минут без учитываемой активности. Для платформы и каждого блока пауза считается отдельно, поэтому посещения блоков не складываются в посещения платформы. Обновление страницы добавляет открытие, но в пределах этой паузы не добавляет посещение.

Учитываются открытия HTML-страниц и запросы действий с ответом HTTP 2xx. Это счётчик запросов, а не завершённых задач; отправка файлов и запросы обработки тоже считаются действиями. Ручные операции автозапуска относятся к выбранному блоку. Фоновые опросы, скачивания файлов, ошибки, перенаправления и задания по расписанию не учитываются. Время открытой вкладки не измеряется.

Статистика доступна только управляющим пользователями. Хранятся только счётчики и даты для локальных учётных записей: без IP-адресов, паролей, адресов страниц и содержимого форм. Данные до начала сбора не восстанавливаются; ноль означает отсутствие учтённой активности.

Как устроен доступ к сервису

ИИ-чат, автозапуск и история доступны всем вошедшим пользователям. В автозапуске и истории отображаются только назначенные блоки. Расписание каждого блока общее для системы.

    Как считается рейтинг

    Новое посещение блока начинается после 30 минут без учитываемой активности в этом блоке. Уникальные пользователи — число локальных учётных записей с активностью в блоке. При равном числе посещений сохраняется порядок блоков в системе.

    Учитываются открытия HTML-страниц и успешные запросы действий (HTTP 2xx), включая ручные операции автозапуска для выбранного блока. Действия — число запросов, а не завершённых задач. Фоновые опросы, скачивания, ошибки и задания по расписанию не учитываются.

    Включена сохранённая активность отключённых и архивных учётных записей. В рейтинг также входят общие разделы: ИИ-чат, автозапуск, голосовые заметки и управление пользователями. Посещения всей платформы не прибавляются к посещениям блоков. Данные до начала сбора не восстанавливаются; ноль означает отсутствие учтённой активности.

    Подключение к системе

    Доступ на сервере

    Доступ к внешним системам. Сохранённые пароли не отображаются. Пустое поле оставляет прежний пароль.

    Облако МО дополнит Яндекс Диск при обновлении ЗиП. Одинаковые файлы учитываются один раз; сбой одного источника не останавливает второй. Согласованные остатки сохранятся.

    Если папка не определяется по ссылке

    Укажите точный путь из вашего облака. Сервер проверит, что он соответствует папке из ссылки.

    Проверяет вход и получение одной записи отчёта Добродела с компьютера-сервера. Проверка может занять до двух минут.

    Три простых шага

    1. Выберите системуУ каждого источника свои настройки доступа.
    2. Сохраните логин и парольЧтобы оставить прежний пароль, не заполняйте поле.
    3. Проверьте подключениеЕсли для системы доступна проверка, её кнопка появится после сохранения.
    Какая система для какого блока?

    Для загрузки заявок сохраните доступ к «АРМ ЕДДС», затем откройте блок ЕДДС и выберите период. Доступ к Доброделу настраивается отдельно и используется только для сбора жалоб.

    Коллективные жалобы

    В доступных блоках пользователя отметьте «Коллективные жалобы — МинЖКХ МО». Для подключения выберите выше «МИНЖКХ и коллективные жалобы · cur.bi.mosreg.ru» и сохраните логин и пароль портала. Одна учётная запись используется обоими дашбордами; сотрудники работают без повторного ввода пароля. Если доступ к МИНЖКХ уже сохранён, вводить его заново не нужно.
