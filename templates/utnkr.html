Контроль проблематики УТНКР

Проект предназначен для автоматического контроля проблематики по УТНКР.

Основные функции:
- запуск проверки из интерфейса;
- получение результата из локального JSON;
- анализ статусов;
- отображение сводных метрик;
- отображение детализации по объектам.

Технологический стек:
- Python
- FastAPI
- Uvicorn
- Jinja2
- Playwright
- HTML/CSS
- Vanilla JavaScript
- JSON
