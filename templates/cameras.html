ИНФОРМАЦИЯ

Контроль запуска камер

Проект предназначен для локальной проверки веб-камер.

Основные функции:
- загрузка Excel/TSV таблицы адресов;
- автоматическая конвертация в data/addresses.tsv;
- проверка статуса камеры;
- отображение результата в HTML-дашборде;
- формирование предписаний;
- локальное хранение истории проверок.

Технологический стек:
- Python
- FastAPI
- Uvicorn
- Jinja2
- HTML/CSS
- Vanilla JavaScript
- JSON/TSV
ОБНОВЛЕНИЕ БАЗЫ

Загрузка адресной таблицы

Поддерживаются форматы: .xlsx, .xlsm, .csv, .tsv. После загрузки файл будет преобразован в data/addresses.tsv.
