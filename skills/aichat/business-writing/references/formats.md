# Краткие рабочие структуры

## Письмо
Адресат и тема → цель → подтверждённые обстоятельства → просьба или предложение → срок, только если задан → контакт, если предоставлен.

## Служебная записка
Предмет → факты и последствия → варианты решения → рекомендуемое действие → требуемое согласование.

## Поручение
Исполнитель → действие → проверяемый результат → заданный срок → способ подтверждения выполнения.

## Доклад
Главный вывод → два-три подтверждающих факта → отклонения и риски → следующие действия.

Не заполняй отсутствующие ФИО, регистрационные номера, даты и подписи вымышленными значениями. Передача проекта не означает отправку адресату.
