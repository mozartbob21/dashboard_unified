# Карта жалоб по воде в МИНЖКХ

Откройте **МИНЖКХ → Карта жалоб по воде** (`/mingkh/water-map`). Доступ определяется назначенным блоком `mingkh`. Карта использует общую тему Нейроны, локальные Leaflet/heat/markercluster и подложку Яндекс Карт либо OpenStreetMap.

Доступны период подачи, вид водоснабжения, ОМСУ и факт ЕЦУР, группы жалоб, тепловая карта и точки с количеством, выделение радиусом или многоугольником, свод по ОМСУ и выгрузка выбранных жалоб в Excel. Периоды «7 дней», «30 дней» и другие заканчиваются последним днём имеющихся данных. Пять координат за пределами Московской области учитываются в итогах и Excel, но не рисуются на карте.

## Подложка карты

Карты МИНЖКХ и ЕДДС используют общую настройку и локальный модуль `static/map-basemap.js`. Яндекс подключён через **Tiles API**: браузер загружает изображения с `https://tiles.api-maps.yandex.ru/v1/tiles/`. В запросе задана `projection=web_mercator`, соответствующая проекции Leaflet; это сохраняет положение точек поверх подложки. Внешний SDK и дополнительные пакеты не нужны. Без ключа по умолчанию остаётся OpenStreetMap (`https://tile.openstreetmap.org/{z}/{x}/{y}.png`). Старые адреса 2ГИС больше не используются.

### Подключение Яндекса на Windows-сервере

1. В [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/) получите ключ именно для пакета **Tiles API**. Ключ другого продукта, например JavaScript API, не подходит. По [инструкции Яндекса](https://yandex.ru/maps-api/docs/tiles-api/quickstart.html) активация занимает до 15 минут.
2. В настройках ключа задайте разрешённый домен Нейроны либо внешний IP, через который компьютеры сотрудников выходят в интернет. Запросы тайлов отправляет браузер сотрудника, поэтому для IP-ограничения нужен адрес выхода его сети, а не внутренний IP сервера вида `10.x.x.x`. Для домена укажите только имя, без протокола и порта. Если сотрудники выходят через разные сети, учтите каждую. Правила и задержка применения настроек — в [документации ограничений](https://yandex.ru/maps-api/docs/tiles-api/limit.html).
3. Откройте `.env` рядом с `app.py` на рабочем сервере и добавьте:

   ```dotenv
   MAP_TILE_PROVIDER=auto
   YANDEX_TILES_API_KEY=сюда_вставьте_полученный_ключ
   ```

   Замените текст после `=` своим ключом. Ключ не нужно присылать в чат или добавлять в Git. `.env` — файл настроек приложения, `.venv` — папка Python; это разные вещи.
4. Перезапустите процесс Нейроны. Если он запущен в PowerShell вручную, нажмите `Ctrl + C` в его окне и снова выполните привычную команду запуска, например:

   ```powershell
   python -m uvicorn app:app --host 0.0.0.0 --port 8000
   ```

5. Откройте карты ЕДДС и МИНЖКХ, нажмите `Ctrl + F5`. При принятом ключе появится подложка Яндекса с его логотипом. Реальную загрузку Яндекс Карт можно проверить только после добавления действующего ключа.

На компьютерах сотрудников нужен HTTPS-доступ к `tiles.api-maps.yandex.ru` для Яндекса и к `tile.openstreetmap.org` для OpenStreetMap. Если после активации карта не появилась, проверьте доступ к выбранному хосту и ограничения ключа; затем нажмите «Повторить» на карте.

Значения `MAP_TILE_PROVIDER`:

| Значение | Поведение |
| --- | --- |
| `auto` или переменная не задана | При непустом `YANDEX_TILES_API_KEY` используется Яндекс, иначе OpenStreetMap. |
| `yandex` | Используется Яндекс. Если ключ пуст, показывается предупреждение о настройке и OpenStreetMap. |
| `osm` | Используется OpenStreetMap; ключ Яндекса не применяется. |

`auto` выбирает поставщика по настройкам, а не проверяет действительность ключа. При отказе Яндекса из-за ключа или сети карта показывает предупреждение; автоматической скрытой смены поставщика нет. Для явного возврата к OpenStreetMap задайте `MAP_TILE_PROVIDER=osm` и перезапустите приложение.

На 05.10.2026 [тариф Tiles API](https://yandex.ru/maps-api/tariffs) — бесплатно до 30 запросов в секунду при соблюдении условий Яндекса. Один запрос загружает один фрагмент карты, а не всю карту. Учитывайте одновременную работу сотрудников и проверяйте актуальные условия в кабинете разработчика. Формат URL и проекция описаны в [документации запроса](https://yandex.ru/maps-api/docs/tiles-api/request.html).

### Какие данные получает поставщик

Внешний запрос содержит номера тайлов (`z/x/y`), по которым видна область просмотра; у Яндекса также передаётся ключ Tiles API. Поставщик получает IP клиента и только origin Нейроны в `Referer` — протокол, адрес и порт, без пути страницы и параметров. Это относится и к внутреннему адресу сервера. Приложение не передаёт поставщику названия, тексты, статусы или координаты отдельных жалоб, логины, пароли и cookies; точки и тепловой слой строятся локально. Общий заголовок приложения `Referrer-Policy: same-origin` сохранён; только изображения тайлов используют `strict-origin-when-cross-origin`.

Ключ Tiles API доступен в браузере авторизованному пользователю карты: это необходимо для прямой загрузки тайлов. Хранение в `.env` защищает от попадания ключа в Git, но не делает браузерный ключ секретным. Используйте ограничения Яндекса по домену или внешнему IP сети. Внешние изображения разрешены CSP только на страницах карт; внешний JavaScript не загружается.

Используется обычный браузерный кэш и заголовки кэширования поставщика. Нет массовой предзагрузки, отключения кэша или случайных параметров в URL тайлов. При сетевой ошибке доступны сообщение и «Повторить»; фильтры и данные жалоб продолжают работать. Доступность внешней подложки зависит от сети и сервиса. Логотип Яндекса поставляется локальным файлом и остаётся видимым поверх его карты; при OpenStreetMap показывается его атрибуция. Для OpenStreetMap действуют [правила использования тайлов](https://operations.osmfoundation.org/policies/tiles/).

## Данные после обновления через GitHub

По разрешению владельца проекта в репозиторий включён компактный начальный архив `services/mingkh/water_map_seed.json.gz` (около 1,6 МБ): 52 520 жалоб с 01.01.2024 по 29.09.2026, источник обновлён 29.09.2026 в 15:05. Он содержит только номер, дату, ОМСУ, вид, адрес, факт, статус и координаты. Исходные 70 МБ, тексты жалоб, авторы и исполняемые скрипты архива не включены.

При первом открытии карта автоматически создаёт рабочий файл `data/mingkh/water-map.json.gz`. Если файл уже существует, начальный архив **никогда не заменяет** его, в том числе после очередного `git pull`. Рабочий файл исключён из Git. На Windows требуется право записи процесса приложения в `data/mingkh`.

Ни начальный, ни рабочий архив не раздаются через статические маршруты. JSON выдаётся только по `/mingkh/api/water-map` после проверки доступа, с запретом кэширования.

## Импорт и дозапись

Администратор с правом управления пользователями и доступом к МИНЖКХ может загрузить ZIP с одним файлом `water_points.json` или непосредственно этот JSON на странице карты. Импорт полностью заменяет рабочий архив после проверки структуры, номеров, дат, координат и ограничений размера. Скрипты из ZIP не запускаются, файлы из него не извлекаются на диск. Размер файла и распакованного JSON ограничен 100 МБ.

Кнопка **«Дозаписать из ДоброДела»** использует сохранённую интеграцию **«Добродел»** из раздела «Пользователи → Логины и пароли». Это отдельный доступ от интеграции аналитического портала МИНЖКХ. Перепроверяется семидневный хвост предыдущего обновления, загружаются новые даты, сохраняются старые координаты. Авторы и тексты жалоб не сохраняются. Метка архива остаётся в данных; интерфейс показывает время дозаписи и перепроверенный период. Старые статусы вне этого периода не перепроверяются.

Автоматическое расписание для карты не создаётся. Обновление запускается по кнопке и выполняется в фоне одного процесса приложения. При ошибке прежний файл сохраняется. Для одного запуска предусмотрены пределы: архив не старше 120 дней, не более 2000 новых карточек с координатами и 20 минут между ограниченными по времени HTTP-запросами. При превышении загрузите более свежий архив.

Для локального импорта из командной строки:

```console
python scripts/import_water_map.py "C:\путь\Жалобы по воде — архив 29.09.2026.zip"
```

Проверки с синтетическими данными, без обращения к порталу:

```console
python -m unittest test.test_mingkh_water_map
```
