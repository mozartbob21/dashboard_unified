# Обновление ЕДДС, карты МинЖКХ и аккаунтов

1. Остановите Нейрону на Windows через Ctrl+C в окне сервера, затем получите изменения из GitHub (`git pull`). Сохранённые доступы и `.env` остаются на сервере.
2. Запустите сервер прежней командой из корня проекта:

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn app:app --host 0.0.0.0 --port 8000
   ```

3. В браузере обновите страницы через Ctrl+F5.
4. В «Пользователи → Логины и пароли → Добродел» нажмите «Проверить вход». Если вход подтверждён, откройте ЕДДС и обновите жалобы. Для Добродела теперь не требуется браузер; настройки Chromium-GOST используются только для АРМ ЕДДС и остаются прежними.
5. В ЕДДС измените период карты. Система запросит свод и координаты заново. При ошибке загрузки показывается прежний период с предупреждением; успешный пустой период очищает карту.
6. В МинЖКХ откройте «Карта жалоб по воде». Начальный архив до 29.09.2026 включён в изменения: отдельная передача исходного ZIP не требуется. Более новые рабочие данные не заменяются. Подробнее: [WATER_MAP.md](WATER_MAP.md).
7. В управлении пользователями выберите аккаунт: появился раздел активности с посещениями, открытиями страниц и действиями по блокам. Сбор начинается после обновления, старую активность восстановить нельзя. Посещение считается новым после 30 минут без активности.
8. Регистрация теперь принимает логин, почту и пароль без письма с кодом. Новые аккаунты не получают рабочие блоки автоматически: их назначает управляющий.

Новые установочные пакеты для этого обновления не требуются. Таблицы статистики создаются при запуске автоматически. Не добавляйте в GitHub `.env`, `.private`, базу аккаунтов и рабочую папку `data`; компактный начальный архив карты уже выделен отдельным исключением в `.gitignore`.
