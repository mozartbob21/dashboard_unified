# Инструменты, ЕДДС и МИНЖКХ — обновление 24.09.2026

## Что добавлено

«Полезные инструменты» теперь содержит шесть разделов:

- **Конвертация:** HTML → PowerPoint и PDF → Word. Word → PDF удалён по решению владельца; LibreOffice и автоматизация Microsoft Word не используются.
- **Страницы PDF:** объединение, извлечение, удаление, изменение порядка, поворот и разделение на отдельные PDF в ZIP.
- **Помощь с макросами:** ГосЧат создаёт модуль VBA для Excel/Word и инструкцию. Код показывается для копирования и скачивается как `.bas` в кодировке Windows-1251 для русской Windows. Макросы на сервере не исполняются.
- **Python → EXE:** администратор собирает один `.py` в Windows Sandbox. Готовый EXE автоматически не запускается.
- **Объединение Excel:** первые листы XLSX/XLS/XLSB объединяются по заголовкам, как в переданном `merge_excel_cli.py`. Можно выбрать файлы или папку. Подпапки, временные файлы и предыдущий результат пропускаются; отдельный лист перечисляет источники. Ошибка чтения останавливает объединение, чтобы строки не потерялись незаметно.

- **Группировка по координатам:** XLSX с заявками преобразуется в объекты с постоянными кодами на основе переданного `кодер объектов.py`.

Шаблоны презентаций и герб общие для организации; любой аккаунт с доступом к инструментам может их использовать и обновлять. Результаты обработки и реестры координат остаются личными. Завершённые результаты хранятся семь дней; удаление устаревших выполняется при следующем обращении аккаунта к инструментам. Загруженные оригиналы удаляются после обработки. **История ИИ-чата по требованию владельца остаётся общей для всех аккаунтов.**

## Обновление офисного сервера Windows

1. Перед обновлением остановите Нейрону. Скопируйте `.env`, папку `data` и свои HTTPS-файлы `cert.pem`/`key.pem` в защищённую резервную папку **вне репозитория**. Ключ и выгрузка `data/cds/appeals.xlsx` больше не должны храниться в Git: обновление удалит старые отслеживаемые копии. На компьютере разработки файлы сохранены.
2. Получите обновление из GitHub привычным способом.
3. В папке проекта выполните:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m playwright install chromium
   ```

4. Для HTML и макросов используется существующий `QWEN_API_KEY` ГосЧата. Адрес по умолчанию — `https://aiplatform.mosreg.ru/api/user-models/v1`. Не помещайте ключ в HTML, JavaScript или Git. При корпоративном УЦ можно указать файл цепочки доверия `AI_CA_BUNDLE`; проверка сертификатов остаётся включённой.
5. Верните собственные рабочие данные из резервной копии при необходимости. Если HTTPS-ключ использовался из репозитория, выпустите новый ключ и сертификат для сервера: исключение из Git **не удаляет старый ключ из истории коммитов**. Обновление сертификата на рабочих местах согласуйте с ИТ.
6. Запустите Нейрону привычным способом. Откройте главную страницу с принудительным обновлением браузера (`Ctrl+F5`).

Все конвертации работают без LibreOffice и установленного Microsoft Word. PDF → Word требует Python-зависимостей из `requirements.txt`. Текстовый PDF преобразуется локально; сканам предварительно нужно OCR, сложную вёрстку после конвертации следует проверить. Лимиты: до 20 МБ на файл, 60 МБ на запрос, PDF → Word до 100 страниц, операции со страницами PDF до 500 страниц суммарно, объединение Excel до 500 000 ячеек.

## Работа со страницами PDF

В **Полезные инструменты → Страницы PDF** выберите действие и загрузите документы. Для объединения можно выбрать от 2 до 20 файлов и поменять их порядок стрелками. Остальные действия работают с одним PDF.

- Страницы указываются с единицы: `1, 3-5`. Обратный диапазон: `5-1`.
- Для изменения порядка перечислите все страницы ровно по одному разу, например `3, 1-2`.
- При повороте и разделении пустое поле означает все страницы. Поворот — по часовой стрелке относительно исходного положения.
- Разделение выдаёт ZIP с отдельным PDF для каждой выбранной страницы. Извлечение выдаёт один PDF с указанными страницами.
- Поддерживаются сканы без распознавания текста. Заполненные поля форм сохраняются как обычное содержимое страниц.
- Лимиты: 20 МБ на файл, 60 МБ на запрос, 500 страниц суммарно. PDF с паролем нужно предварительно разблокировать самостоятельно.

Используется PyMuPDF, уже входящий в зависимости PDF → Word. Минимальная версия для корректной обработки форм закреплена в `requirements.txt`. LibreOffice, установленный Word и внешние сервисы не нужны. Полученный результат доступен только аккаунту, который запустил обработку.

## Общее оформление презентаций

Шаблоны и герб хранятся в `data/tools/branding/`. При первом открытии конвертера старые файлы из `data/tools/templates/` и личных папок автоматически копируются в общее хранилище. Оригиналы остаются на месте; разные шаблоны с одинаковым именем получают разные имена. Удалённые общие шаблоны повторно не импортируются.

Если найдено несколько разных гербов, сохраняются все исходные варианты. Общим становится прежний организационный герб, а при его отсутствии — последний загруженный. Интерфейс показывает выбранный герб и сообщение, что его нужно проверить; загрузка нового изображения заменяет общий вариант. Копии прежних гербов находятся в `data/tools/branding/previous-emblems/`.

Изменения оформления доступны всем аккаунтам с правом на инструменты. Уже поставленные в очередь презентации используют копию оформления на момент запуска. Общий герб применяется к стандартным слайдам и корпоративному шаблону. В режиме «Сохранить внешний вид» шаблон и герб не накладываются поверх HTML.

## Группировка по координатам

1. Откройте **Полезные инструменты → Группировка по координатам**.
2. Выберите XLSX. На первом листе, в первой строке должны быть заголовки «Широта»/«Долгота» либо «Координаты». ОМСУ, РСО и номер заявки подхватываются, если они есть.
3. Укажите радиус (по умолчанию 500 м). Префикс кодов можно задать вручную; иначе он берётся из «тип VZ» в имени файла, при отсутствии — `OBJ`.
4. При необходимости приложите старый реестр XLSX или ранее скачанный результат с листом «Реестр». Противоречащие существующим кодам записи не перезаписываются.
5. Нажмите **Сгруппировать** и скачайте Excel с листами «Объекты», «Записи», «Без координат» и «Реестр».

Поддерживаются десятичные координаты и градусы/минуты/секунды в пределах Московской области. Строки с ошибочными координатами сохраняются отдельно с причиной. Часто повторяющиеся условные точки округов выделяются цветом.

Новые группы объединяются только при расстоянии между каждой парой точек не больше радиуса. Известные объекты сопоставляются с центрами личного реестра, чтобы сохранять прежние коды. Реестр находится на сервере в `data/tools/accounts/<идентификатор>/coordinate_registry.json`, переживает перезапуск и отделён от реестров других аккаунтов. Не удаляйте его при обновлении. В ЕДДС собственный реестр карты хранится в браузере для текущего аккаунта; для переноса между инструментами используйте лист «Реестр».

Лимиты: 20 МБ, 30 000 строк, 200 столбцов, 500 000 ячеек и 8 000 разных точек; слишком плотные выборки нужно разделить по округам. Обработка локальная, без геокодирования и отправки таблиц наружу.

## Обновление ЕДДС

Встроен дашборд из «ЕДДС-мониторинг (2)»: дополнительные фильтры сворачиваются, на карте можно выбирать область многоугольником или кругом, группировать заявки в объекты и работать с реестром кодов. Для Excel можно выбрать нужные листы; результат группировки содержит реестр для следующего импорта.

Сохранены темы Нейроны, общая шапка, загрузка АРМ через сервер и существующая настройка Chrome/сертификатов. Жалобы загружаются через защищённый маршрут Нейроны, библиотеки и тайлы карты — локальные. Файлы демонстрационных жалоб из архива рабочие данные не заменяют. После обновления выполните `Ctrl+F5`.

## Изображения в презентациях

- Встроенные в HTML картинки сохраняются.
- Изображения можно выбрать с компьютера. Имена сопоставляются с `<img src="имя-файла.png">`; неиспользованные картинки добавляются отдельными слайдами.
- Опция **«Загружать картинки по интернет-ссылкам»** включена по умолчанию. Загружаются публичные HTTP/HTTPS-изображения, в том числе фоны в CSS внутри HTML. Скрипты и внешние CSS не исполняются и не подгружаются.
- Сервер не передаёт сайту картинок содержимое документа, авторизационные cookies или ключ ГосЧата. Сам адрес картинки, IP сервера и обычные заголовки запроса видны её поставщику — это необходимо для скачивания.
- Внутренние/служебные IP, адреса с логином и паролем и небезопасные перенаправления блокируются. IP проверяется и фиксируется на время соединения, чтобы повторный DNS-запрос не перенаправил скачивание во внутреннюю сеть.
- Максимум 20 внешних изображений, до 8 МБ каждое, суммарно 24 МБ. Если изображение не загрузилось, результат сопровождается предупреждением; можно приложить файл с компьютера.
- Режим «Сохранить внешний вид» сохраняет слайды картинками; «Структура HTML» создаёт редактируемые элементы; «ГосЧат — ИИ-дизайнер» передаёт в разрешённый ИИ текстовую структуру, а картинки вставляет локально.

## Подключение МИНЖКХ

1. На офисном компьютере проверьте доступ к `https://cur.bi.mosreg.ru`.
2. Войдите в Нейрону под аккаунтом, который управляет пользователями.
3. Откройте **Пользователи → Логины и пароли → МИНЖКХ** и сохраните логин/пароль портала. Пароль хранится зашифрованным и не возвращается браузеру.
4. В правах нужных аккаунтов включите **«МИНЖКХ — дашборд обращений»**. Существующим аккаунтам новый блок автоматически не выдаётся.
5. На главной откройте карточку **«Дашборд МИНЖКХ»**. Выберите период и нажмите «Обновить сейчас».

Перенесены фильтры, сравнение периодов, муниципальная тепловая карта и настройки автообновления из переданного дашборда. Обновление «Дашборд МИНЖКХ2» добавляет загрузку периодов частями по 30 дней (до четырёх запросов одновременно), повтор временных ошибок и удаление повторяющихся обращений по внутреннему ID. Строки без ID сохраняются. Ошибка хотя бы одной части не позволяет показать неполный период. Windows EXE из архива не запускается. Запросы выполняет сервер Нейроны к фиксированному адресу Pentaho; браузер не получает пароль портала. При неполной загрузке сравнительных периодов отчёт не выдаёт отсутствующие данные за нулевые.

Проверка TLS использует доверенные сертификаты ОС. Если нужен дополнительный УЦ, укажите `MINGKH_CA_BUNDLE=C:\Certificates\mosreg-ca.pem` и перезапустите приложение. `verify=False` не требуется. Живую авторизацию и выгрузку необходимо проверить в офисной сети с рабочими реквизитами.

## Подготовка Python → EXE

Сборка использует Windows Sandbox, которая доступна в поддерживаемых редакциях Windows Pro/Enterprise/Education. Она требует виртуализации и интерактивного сеанса пользователя: при запуске Нейроны службой без рабочего стола этот способ не подходит.

1. Включите **«Песочница Windows»** в компонентах Windows и перезагрузите компьютер. Проверьте, что она открывается из меню «Пуск».
2. Установите отдельный полный Python с официального сайта, например в `C:\NeuronaBuild\Python`. Не используйте виртуальную среду или папку самой Нейроны: в этой среде не должно быть рабочих документов, `.env` и ключей.
3. Подготовьте её заранее:

   ```powershell
   C:\NeuronaBuild\Python\python.exe -m pip install pyinstaller
   ```

   Если скриптам нужны pandas, openpyxl или другие доверенные зависимости, установите их тем же Python заранее. Во время сборки сеть отключена и пакеты не скачиваются.
4. В `.env` Нейроны добавьте:

   ```dotenv
   TOOLS_BUILD_RUNTIME=C:\NeuronaBuild\Python
   ```

5. Перезапустите Нейрону. Под администратором с доступом к инструментам откройте **Python → EXE**, выберите `.py` и запустите сборку.

Sandbox получает только выбранный скрипт, отдельную среду Python в режиме чтения и папку результата. Сеть, буфер обмена, принтеры, камера и микрофон отключены. Сборка ограничена десятью минутами. Это Windows-сборка; на macOS инструмент показывает необходимость настройки Windows, а не подменяет EXE другим форматом.

Основания: [Windows Sandbox — конфигурация](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-configure-using-wsb-file), [PyInstaller — режим работы](https://pyinstaller.org/en/stable/operating-mode.html).

## Что изменено для защиты данных

- ИИ-запросы допускаются только к ГосЧату или модели на loopback-адресе этого сервера. Другие внешние ИИ, включая GigaChat, отключены. Произвольные прокси и перенаправления для ИИ-запросов не используются.
- Общая история чата сохранена. Данные закрытых модулей больше не подмешиваются к каждому сообщению незаметно; в ГосЧат передаются текст запроса, история выбранного общего диалога и явно прикреплённые пользователем файлы. Сводку платформы можно добавить опцией «Добавить данные моих модулей»: сервер читает только модули, разрешённые текущему аккаунту; ответ остаётся в общей истории.
- Рабочие результаты конвертации защищены проверкой аккаунта. Прямое скачивание ключей, профилей браузеров, базы авторизации и папок инструментов через `/data` блокируется.
- Добавлены проверка источника изменяющих запросов, ограничения загрузки и CSP, запрещающая браузеру отправлять рабочие данные на сторонние адреса. Библиотеки Excel, графиков и карты поставляются локально.
- Из DOCX/PPTX исключены макросы, встроенные программы и автоматически загружаемые внешние ресурсы. Конвертация HTML не читает произвольные файлы сервера.
- Проверка HTTPS-сертификатов включена также в CDS и проверке камер. Для внутренних сертификатов настройте доверие к УЦ на сервере; при недоверенном сертификате запрос теперь завершится ошибкой.
- Карта ЕДДС больше не обращается к внешнему поставщику тайлов. Точки и тепловой слой работают локально; для географической подложки ИТ может разместить разрешённые тайлы в `static/map-tiles/{z}/{x}/{y}.png`. Без них будет предупреждение об отсутствии подложки.

Это меры внутри приложения, а не гарантия безопасности всей ОС. Доступ к серверу, резервным копиям, истории Git и исходящим соединениям контролируется отдельно. Рабочие интеграции с порталами, почтой и Telegram продолжают обращаться к своим сервисам; ГосЧат и загрузка внешних картинок разрешены владельцем проекта.
