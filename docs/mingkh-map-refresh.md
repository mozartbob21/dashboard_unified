# Автоматическое обновление карты жалоб МинЖКХ

Карта `/mingkh/water-map` обновляется через существующий планировщик. Новая задача
`mingkh-water-map` включается один раз при первом создании с интервалом 120 минут;
первая проверка назначается через два часа. Перезапуск приложения не меняет
сохранённые администратором интервал, включение, следующую дату или результат.
Сервер должен оставаться запущенным; пропущенная во время остановки проверка
выполняется после возвращения планировщика.

Задача использует сохранённую интеграцию «Добродел» (`edds`). Секреты не входят
в расписание, команды или историю. Настроить доступ может управляющий
пользователями. При отсутствии доступа сохраняются прежние данные и понятная
ошибка в истории; следующая попытка следует расписанию.

Сборщик дописывает недостающий период и перепроверяет последние семь дней,
сохраняет раннюю историю и уже полученные координаты. Сохраняются существующие
ограничения: до 120 дней отставания, 20 минут на обновление и до 2000 запросов
недостающих координат. Неполный или ошибочный ответ портала не заменяет карту.
Готовый файл публикуется атомарно.

Ручное обновление и планировщик используют один сборщик в процессе приложения.
Общая блокировка потоков и файловая блокировка Windows/POSIX не допускают
одновременной замены данных другим обновлением или импортом, включая другие
процессы сервера. История запусков записывается под `mingkh-water-map`; этот
идентификатор связан с правом `mingkh` для фильтрации истории и учёта действий.

Обычные пользователи видят карту, фильтры, выгрузку и статус автоматического
обновления. Открытая вкладка проверяет статус раз в минуту (во время сбора —
раз в три секунды) и принимает новую версию данных, сохраняя фильтры и область
карты. В скрытой вкладке сетевые проверки приостанавливаются.

Импорт архива и ручной запуск находятся в закрытом разделе «Обслуживание
данных» только у управляющего пользователями с доступом к МИНЖКХ. Эта же
проверка защищает новую задачу в разделе «Автозапуск» и его API; права на
остальные задания планировщика не изменены. При отключённом расписании
страница сообщает о паузе вместо обещания обновления каждые два часа.

## Проверка без внешнего портала

```sh
python -m pytest -q -p no:cacheprovider test/test_mingkh_water_map.py test/test_mingkh_water_map_schedule.py test/test_mingkh_water_map_ui.py
node test/test_mingkh_water_map_ui.js
```

Проверки используют временные БД и наборы данных, подставной клиент портала и
локальный дочерний процесс для проверки файловой блокировки. Реальные запросы
к Доброделу не выполняются.
