# ИИ-чат: справка и данные платформы

Подключение Qwen, ключ, модель, режим работы транспорта и параметры `.env` не изменены. Чат остаётся универсальным: обычные вопросы, тексты, файлы и ИИ-команды работают через прежний адаптер.

## Где проверить

На главной откройте **ИИ-чат**. Примеры запросов:

- «Как сохранить доклад в коллективных жалобах?» — инструкция по реальным кнопкам без чтения показателей.
- «Дай краткий отчёт по коллективным жалобам» — сохранённые обращения, назначения и доклады, если аккаунту доступен этот блок.
- «Дай отчёт по коллективным жалобам по Химкам с 13.10.2026 по 19.10.2026» — явно заданные территория и период.
- «А теперь по Балашихе?» — продолжение с выбранными блоками и периодом.
- «Объясни, как устроен DNS» — обычный ответ ИИ без данных рабочих блоков.

Сначала загрузите нужный период в самом дашборде. Чат не обновляет портал и не изменяет карточки. Если нет подтверждённых данных за период, он сообщает об ограничении; данные за другую дату не заменяют запрошенные. Вопросы о СМС пока не используют этот реестр автоматически: можно приложить выгрузку. Неуспешная пустая проверка источника не считается нулём нарушений.

## Как устроено

- `platform_guide.py` содержит проверенную справку по текущему интерфейсу. В неё включаются только доступные аккаунту блоки; админ-действия — только после серверной проверки прав. При изменении кнопок справку нужно обновлять вместе с интерфейсом.
- Запросы показателей получают контекст из сохранённых источников. В режиме навыков включённый `platform-report` читается независимо от того, выбрала ли его модель. Явное отключение данных и отключённый навык соблюдаются. Сбой каталога навыков оставляет обычный чат доступным.
- Коллективные жалобы подключены отдельным адаптером с правом `collective`. Ручной доклад передаётся как сообщение сотрудника с датой, а не как проверенный факт. Контекст имеет ограничения размера и отмечает сокращённые строки.
- Период хранится в истории запроса и сверяется с периодом каждого источника. Дата получения не подменяет период данных. Для нескольких источников показываются ограничения покрытия.
- Старые реплики ограничиваются целыми парами вопрос/ответ. Текущий вопрос и текущие данные не отрезаются ради старого диалога. Системная инструкция требует разделять факты, гипотезы и рекомендации.

Источники и вложения остаются справочными данными, а не инструкциями для изменения прав или поведения. В технические журналы не добавлены тексты вопросов, докладов или ключи.

## Проверка и ограничения

Контрактные тесты проверяют реальные сборку запроса, маршрутизацию, сохранение периода, права, ошибки источников и передачу данных; ответ модели подменяется тестовым. Это подтверждает подготовку данных для Qwen, но не качество живого ответа офисной модели. Его нужно оценить на сервере на типовых запросах после переноса кода.

Рабочая модель, портал МинЖКХ и Windows-сервер при разработке не вызывались. Деплой не выполнялся. Изменения ИИ-чата не требуют новой схемы; отдельная миграция коллективных жалоб описана в `collective-workspace.md`; рабочие JSON, БД и `.env` в Git не включаются.


### Итоговая проверка 19.10.2026

Общий прогон изменений коллективных жалоб, контекста и транспорта ИИ-чата, навыков, файлов и уведомлений: **487 Python-тестов и 124 дополнительных сценария прошли**. **62 JavaScript-теста прошли**. Предупреждения прогона относятся к существующим устаревающим привязкам библиотеки SWIG; падений нет.

Компоновка коллективных жалоб проверена в Яндекс Браузере на отдельной временной БД: 32 тестовых обращения, 12 ОМСУ, светлая/тёмная тема, обычная и узкая ширина. Подтверждены высота списка, порядок таблиц и автоматическая загрузка при смене периода. Тестовый сервер остановлен, вкладка закрыта, тема и масштаб восстановлены.
