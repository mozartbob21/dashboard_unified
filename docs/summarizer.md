# Сумматор: Госчат и история

Сумматор использует Госчат/Qwen по умолчанию. Также доступен локальный алгоритм. Подключение GigaChat удалено: его старые переменные окружения больше не используются и запросы к нему не отправляются. Сохранённые отчёты и их версии остаются в истории с указанием того движка, который действительно подготовил результат.

## После обновления из GitHub

1. Сохраните рабочие настройки Qwen в серверном `.env`: `QWEN_API_BASE`, `QWEN_API_KEY`, `QWEN_MODEL`. Адрес также можно задавать через `QWEN_BASE_URL`; приоритет у `QWEN_API_BASE`.
2. Если сумматору задан отдельный `SUMMARIZER_QWEN_API_KEY`, используется он; иначе — общий `QWEN_API_KEY`. Значения ключей не нужно присылать или включать в Git.
3. `SUMMARIZER_BACKEND=qwen` выбирает Госчат для варианта «По настройкам сервера». Без настройки используется Госчат; `SUMMARIZER_BACKEND=algo` сохраняет локальный режим. Старое значение `gigachat` автоматически трактуется как `qwen`, поэтому его наличие не возвращает подключение GigaChat.
4. Перезапустите Нейрону, обновите страницу Ctrl+F5, откройте сумматор и выберите **Госчат**.

При пересборке старого отчёта GigaChat новый результат формируется через Qwen. Исходный отчёт и старые версии сохраняются. ИИ-чат, макросы и HTML-конвертер продолжают использовать свои действующие настройки Qwen.

Дополнительные Python-пакеты не нужны. Проверка TLS остаётся включённой; при отдельной цепочке доверия используется `AI_CA_BUNDLE`. Если ИИ не отвечает, результат запасного алгоритма помечается как **Алгоритм**, рядом показываются предупреждение и безопасный код ошибки. Такой результат не выдаётся за ответ ИИ.

## История

Внизу страницы каждая запись показывает дату, автора, движок, статус, начало исходного текста и результата. Нажмите «Открыть полностью»: исходник и результат откроются рядом. Можно переключать версии и копировать текст. Текущий черновик в поле ввода при этом не меняется.

Кнопка «К согласованию» открывает актуальную версию в рабочей области. После доработки сохраняются и прежний результат, и новая версия вместе с отправленным комментарием. Ошибка, из-за которой пересобранный результат не записывался на диск, исправлена.

История хранится локально в `data/summarizer/reports.json` и доступна пользователям с доступом к сумматору. В новой записи сохраняется полный принятый текст (до 200 000 символов). Старые записи читаются без миграции; если прежняя версия обрезала исходник на 20 000 символах, утраченный остаток восстановить невозможно — интерфейс показывает предупреждение. В общий журнал запусков полные тексты не копируются.

Красная корзина справа удаляет одну запись вместе с исходником, результатом и всеми версиями. «Очистить всё» над списком удаляет всю историю, включая следующие страницы. Обе операции требуют подтверждения, доступны пользователям с доступом к сумматору и действуют на общую историю всех сотрудников. Удалённые записи не восстанавливаются. Черновик в поле ввода сохраняется.
