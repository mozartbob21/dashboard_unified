# Сумматор: GigaChat и история

В сумматоре снова доступен GigaChat; на странице он выбран по умолчанию. ИИ-чат, макросы и HTML-конвертер продолжают использовать Qwen. Автоматического переключения этих инструментов на GigaChat нет.

## После обновления из GitHub

1. Сохраните прежние ключи в серверном `.env`. Сумматор сначала использует `SUMMARIZER_GIGACHAT_CREDENTIALS`, а если он пуст — `GIGACHAT_CREDENTIALS`.
2. `GIGACHAT_SCOPE=GIGACHAT_API_PERS` поддерживается. Если используется другой тип API, укажите соответствующий scope.
3. Имя модели читается из `GIGACHAT_MODEL`; также поддерживается существующее имя `GIGACHAT_MODE`. Если заданы оба, приоритет у `GIGACHAT_MODEL`. Без значения используется прежняя модель `GigaChat-2-Pro`.
4. Перезапустите Нейрону, обновите страницу Ctrl+F5, откройте сумматор и выберите **GigaChat**.

Клиент использует уже установленный `httpx`, поэтому дополнительные Python-пакеты для восстановления GigaChat не нужны. Запросы авторизации и генерации реализованы по [официальной документации GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-token). OAuth-токен обновляется по сроку действия; при его отклонении выполняется один повтор авторизации. Настройки адресов и scope сверены с [официальным SDK](https://github.com/ai-forever/gigachat/blob/main/README.md).

Проверка сертификата включена. Используется доверенное хранилище Python/Windows; для отдельной цепочки сертификатов можно указать `GIGACHAT_CA_BUNDLE_FILE` (либо общий `AI_CA_BUNDLE`). При `AI_TLS_ERROR` настройте доверенный сертификат на сервере. Ключи и тексты запросов не попадают в журналы диагностики.

Стандартный адрес генерации — `https://api.giga.chat/v1`. При необходимости прежнего адреса можно указать `GIGACHAT_BASE_URL=https://gigachat.devices.sberbank.ru/api/v1`. Другие адреса для GigaChat не принимаются. Авторизация идёт через официальный OAuth endpoint, без передачи ему исходной переписки.

`SUMMARIZER_BACKEND` задаёт вариант «По настройкам сервера». Явный выбор GigaChat/Госчат/Алгоритм на странице имеет приоритет. Если выбранный ИИ не отвечает, результат запасного алгоритма помечается как **Алгоритм**, рядом показываются предупреждение и безопасный код ошибки. Он не выдаётся за ответ ИИ.

## История

Внизу страницы каждая запись показывает дату, автора, движок, статус, начало исходного текста и результата. Нажмите «Открыть полностью»: исходник и результат откроются рядом. Можно переключать версии и копировать текст. Текущий черновик в поле ввода при этом не меняется.

Кнопка «К согласованию» открывает актуальную версию в рабочей области. После доработки сохраняются и прежний результат, и новая версия вместе с отправленным комментарием. Ошибка, из-за которой пересобранный результат не записывался на диск, исправлена.

История хранится локально в `data/summarizer/reports.json` и доступна пользователям с доступом к сумматору. В новой записи сохраняется полный принятый текст (до 200 000 символов). Старые записи читаются без миграции; если прежняя версия обрезала исходник на 20 000 символах, утраченный остаток восстановить невозможно — интерфейс показывает предупреждение. В общий журнал запусков полные тексты не копируются.
